# Chikura brand — "Vault C"

Monochrome, geometric, no kanji dependency.

- `chikura-mark-dark.svg` — white vault for dark UI (app header, rail, taskbar on dark)
- `chikura-mark-light.svg` — black vault for light UI
- In-app vector: `composeApp/.../ui/theme/ChikuraLogo.kt` (`ChikuraMark`) — same geometry in Canvas, crisp 16px to 512px

Geometry: 64 grid, vault radius 18 (28%), C ring 280deg sweep with 80deg
opening on the right (inbox intake), stroke 6 round caps, core dot r=4
(the one good curated link the vault protects).
